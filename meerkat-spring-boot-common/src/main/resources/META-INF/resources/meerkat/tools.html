把存活对象写成 .hprof 文件并下载，可用 Eclipse MAT、VisualVM 或 IntelliJ IDEA 分析。文件先写到服务器临时目录，下载结束后立即删除。

生成期间应用会完全停顿，堆越大停顿越久；文件大小接近已用堆内存，会占用同样大小的磁盘空间和浏览器下载空间。Dump 包含内存中的全部数据（密码、令牌、个人信息），请妥善保管。

查看配置项的最终值，以及按优先级排列的所有定义了它的配置源（命令行、环境变量、application.yml 等），排在第一位的生效。用于排查“配置为什么没生效”。值不做脱敏。

查看一个类实际从哪个 Jar 加载、类路径上有几份副本以及类加载器链；或扫描类路径找出在多个 Jar 中重复出现的类。查询只加载类、不初始化类。

工具箱的所有操作都在点击时才执行，不会在后台持续运行；临时日志级别到期自动恢复，应用关闭时也会恢复。修改日志级别、CPU 采样、堆直方图、下载堆 Dump、查看配置值和扫描重复类需要 canOperate 权限。
